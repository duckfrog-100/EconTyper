# 학습 마무리 흐름 설계

## 목표
회원가입 없이도 사용자가 한 번의 필사 세션에서 확인한 단어를 모으고, 중요한 단어를 브라우저에 저장하며, 학습 종료 후 결과를 확인하고 틀린 문장만 다시 연습할 수 있게 한다.

## 범위
- 사전 조회 성공 단어를 현재 세션 단어장에 자동 기록
- 사용자가 선택한 단어를 `localStorage`의 내 단어로 저장
- 단어장 드로어에서 검색·삭제·전체 초기화
- 학습 결과 요약에서 완료 문장 수, 전체 정확도, 새로 본 단어 수, 내 단어 저장 수, 오답 문장 수 표시
- 오답 문장만 새 연습 세션으로 다시 시작
- 내 단어 CSV 내보내기 및 가져오기

## 제외 범위
- 회원가입과 서버 동기화
- 기기 간 동기화
- Anki APKG 직접 생성
- 간격 반복 학습 알고리즘
- AI 문맥 사전

## 저장 모델
### 현재 세션 단어
`sessionStorage`에 연습 세션 ID별로 저장한다. 뜻 조회가 성공한 최초 시점에 정규화된 소문자 단어를 키로 중복 제거한다.

### 내 단어
`localStorage`에 저장한다. 같은 브라우저에서 재접속해도 유지되며, 브라우저 데이터를 삭제하거나 다른 기기를 사용하면 복구되지 않는다는 안내를 표시한다.

```ts
export type SavedWord = {
  word: string;
  meaning: string;
  phonetic?: string;
  partOfSpeech?: string;
  exampleSentence?: string;
  sourceTitle?: string;
  addedAt: number;
};
```

## 사용자 흐름
1. 사용자가 원문의 단어에 마우스를 올린다.
2. 사전 조회가 성공하면 해당 단어가 현재 세션 단어장에 자동 추가된다.
3. 사용자는 단어장 드로어에서 별표를 눌러 내 단어로 저장할 수 있다.
4. 모든 문장을 완료하거나 결과 보기 버튼을 누르면 학습 요약을 확인한다.
5. 오답이 있는 경우 틀린 문장만 다시 연습한다.
6. 내 단어는 CSV로 내보내거나 기존 CSV를 가져올 수 있다.

## 화면 구성
### 연습 화면 상단
- `단어장 (N)` 버튼
- 현재 세션에서 조회한 고유 단어 수 표시

### 단어장 드로어
- 검색 입력
- 현재 세션 단어 목록
- 각 단어의 뜻, 발음, 품사
- `내 단어로 저장` 토글
- 세션 단어 개별 삭제 및 전체 초기화
- 내 단어 CSV 내보내기·가져오기
- 로컬 저장 안내

### 결과 요약
- 완료 문장 수
- 전체 정확도
- 새로 본 단어 수
- 내 단어로 저장한 수
- 오답 문장 수
- `틀린 문장 다시 연습` 버튼
- `전체 다시 연습` 버튼
- `홈으로` 버튼

## 오답 기준
문장을 완료하기 전까지 한 번이라도 잘못된 문자를 입력한 문장을 오답 문장으로 기록한다. 최종 입력이 정확해도 오답 기록은 유지한다. 단순히 미완료 상태인 문장은 오답이 아니라 미완료로 분리한다.

## 오류 처리
- 사전 조회 실패 단어는 저장하지 않는다.
- 손상된 저장 데이터는 빈 배열로 대체한다.
- CSV 가져오기에서 필수 열 `word`, `meaning`이 없으면 적용하지 않고 오류 메시지를 표시한다.
- 중복 단어를 가져오면 최신 행으로 병합한다.
- 브라우저 저장소 접근이 차단된 경우 현재 화면 상태로만 동작하고 안내를 표시한다.

## 테스트 기준
- 동일 단어를 여러 번 조회해도 세션 단어에는 한 번만 저장된다.
- 별표 토글 시 내 단어가 추가·삭제된다.
- 새로고침 후 내 단어가 유지된다.
- 오답 입력 이력이 있는 문장만 복습 대상이 된다.
- CSV 내보내기 후 다시 가져오면 동일한 단어 데이터가 복원된다.
- 손상된 저장 데이터와 잘못된 CSV가 앱을 중단시키지 않는다.
